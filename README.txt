PORTOFOLIO VIQRI ALFAHREZI
==========================

Struktur:
- index.html : struktur halaman
- style.css  : gaya dan layout responsif
- script.js  : navigasi dan interaksi
- assets/foto.png : foto profil awal (ganti dengan foto pilihanmu)

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder portfolio-viqri di Visual Studio Code.
3. Buka index.html di browser atau gunakan Live Server.

Catatan:
- Ubah tautan Behance contoh di index.html ke tautan proyek milikmu.
- Periksa username Instagram sebelum dipublikasikan.
- Untuk GitHub Pages, unggah isi folder ini ke repository dan pilih Settings > Pages > Deploy from a branch > main > /(root).
